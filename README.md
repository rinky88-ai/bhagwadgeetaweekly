This is a simple web based app which is used to generate Bhagwad Gita Sloka every week.
The page , contains a simple Landing page where user enter their Name and Age (We are not saving user details for privacy reason)
Once they click submit, they will be able to view the Bhagwad Gita Sloka for the current week.
Translation of the sloka is available in English, Bengali, Oria, Kannada
Transliteration of the sloka is available in english. It is generated using AI (chat_gpt_5.4_mini) based on the age of user who logged in.
The transliteration is clubbed into 3 age group 5-7,8-12,13-16 and have age appropriate context about the sloka.
The meanings of the Bhagwad Gita sloka, Transliteration and translation generated using AI is stored in NeonDB so as to ensure persistent storage and limited use of tokens everytime user log in.
